# 06_Troubleshooting 生产排障与故障复盘库

## 目录说明
本目录是知识库的**实战排障与事故复盘专区**。专门沉淀生产一线真实发生的重大故障复盘报告（Post-Mortem / RCA）、疑难杂症排查决策树以及各组件的生产终极排障手册，按「现象 ──► 根因 ──► 止血 ──► 根治」的标准闭环进行经验资产沉淀。

## 核心价值
- **一线实战踩坑沉淀**：摆脱理论纸上谈兵，沉淀真实的系统崩溃、死锁、网络超时、集群裂脑等实战案例；
- **RCA 根因闭环**：通过 5 Whys 深入分析流程与配置漏洞，杜绝相同故障二次发生；
- **排障效率倍增**：遇到突发线上故障时，可按决策树快速定位止血。
