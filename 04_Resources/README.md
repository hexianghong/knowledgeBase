# 04_Resources 静态资源与多媒体中心 (Assets & References)

---

## 🎯 目录定位与核心价值

- **核心定位**：知识库的**静态资产仓库与外部参考输入中心**。集中存放架构拓扑高清原图、PDF 电子书、外链参考文档、技术白皮书及官方规范。
- **核心价值**：
  1. **资产集中统一管理**：避免图片和附件散落在各个子目录中造成混乱，保证整个工作区整洁；
  2. **可移植相对路径引用**：供全库所有 Markdown 笔记通过相对路径（如 `../04_Resources/xxx.png`）安全引用，杜绝绝对路径导致的跨机器死链；
  3. **权威背书与溯源**：沉淀原始论文、官方 RFC 与架构白皮书，作为深度文章的技术溯源依据。
