# AI 学习方向全景图

为了系统性地提升 AI 能力并获取高质量的学习资料，我们可以将 AI 的学习方向从**“入门应用”**到**“底层硬核开发”**进行分层梳理。你可以根据自己的背景（是否有编程基础、是否偏向应用或研究）来选择 1-2 个重点方向进行深耕。

## 1. ⚡ 超级个体应用层（适合所有人，追求效率和工具利用）
这个方向不需要深厚的代码功底，重点在于“如何用好现有的 AI 工具来放大自己的能力”。

*   **提示词工程 (Prompt Engineering)**：学习如何与大模型高效对话，掌握结构化提示词（如 CRISPE 模型）、Few-shot、思维链（CoT）等技巧。
*   **AI 辅助编程与工作流 (AI Coding & Workflow)**：利用 Cursor、GitHub Copilot 等工具辅助写代码；利用 Dify、Coze、FastGPT 等平台搭建无需写代码的 AI 机器人和自动化工作流。
*   **多模态内容生成 (AIGC)**：
    *   **图像生成**：Midjourney 的进阶使用、Stable Diffusion (配合 WebUI/ComfyUI 的节点式生图、ControlNet 精准控制)。
    *   **音视频生成**：Runway、Sora、Kling、Suno 的使用技巧。

## 2. 🧠 AI 应用开发层（适合有一定编程基础的开发者）
这个方向是目前市场上需求最旺盛的领域，主要关注“如何把 AI 能力集成到自己的产品或系统中”。

*   **API 接入与后端开发**：学习 OpenAI, Anthropic, Gemini, 以及国内大模型（DeepSeek, 阿里通义等）的 API 接入与调用策略。
*   **RAG (检索增强生成) 架构**：这是目前企业最常用的技术。学习文本切分 (Chunking)、向量化 (Embedding)、向量数据库 (Pinecone, Milvus, Qdrant) 以及检索策略优化。
*   **AI Agent (智能体) 开发**：学习如何让大模型拥有“手和脚”（调用工具、规划任务）。重点框架：LangChain, LlamaIndex, AutoGPT, CrewAI，以及 ReAct 机制。

## 3. ⚙️ 模型微调与部署层 (进阶开发者/AI 工程师)
如果你不仅想用现成的 API，还想自己训练或改造开源模型，这就是必经之路。

*   **本地大模型部署**：学习使用 Ollama, vLLM, LMDeploy 等工具在本地或私有服务器上高效运行 Llama 3, Qwen 等开源模型。
*   **参数高效微调 (PEFT)**：学习在算力有限的情况下，如何让模型具备特定领域的知识。重点技术：LoRA, QLoRA, Ptuning。
*   **模型量化与加速**：了解 GGUF, AWQ, GPTQ 等量化技术，降低模型运行的显存门槛。

## 4. 📚 算法原理与底层基石 (适合研究员/算法工程师)
这是最硬核的方向，需要扎实的数学和计算机基础。

*   **数学基础**：线性代数、微积分、概率论与数理统计。
*   **传统机器学习 (ML)**：线性回归、决策树、随机森林、SVM、聚类算法（Scikit-learn）。
*   **深度学习 (DL)**：神经网络基础、CNN (卷积神经网络)、RNN。熟练使用 PyTorch 或 TensorFlow 框架。
*   **大语言模型架构 (LLM)**：深入理解 Transformer 架构的 Self-Attention 机制；了解 Pre-training (预训练)、SFT (监督微调) 和 RLHF (基于人类反馈的强化学习) 的全流程。
