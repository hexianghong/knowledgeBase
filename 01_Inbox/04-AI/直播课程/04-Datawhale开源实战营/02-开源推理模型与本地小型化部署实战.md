## 1. 核心实战：GGUF 量化选型与 30 秒极速启动

```mermaid
flowchart LR
    HuggingFace[HuggingFace 原生 FP16 模型权重] --> Convert[llama.cpp convert-hf-to-gguf.py]
    Convert --> Quantizer{量化级别选择}
    Quantizer -->|Q4_K_M (首选平衡)| Q4_Weight[仅需 4.5GB 显存 (RTX 3060/4060 极速运行)]
    Quantizer -->|Q8_0 (近无损精度)| Q8_Weight[8GB 显存]
    Q4_Weight & Q8_Weight --> OllamaEngine[Ollama 引擎 / WebUI / API 统一暴露]
```

### 1.1 一行命令启动本地 DeepSeek-R1 蒸馏模型

```bash
# 启动 7B 蒸馏版（具备完整 CoT 思考能力）
ollama run deepseek-r1:7b

# 通过 OpenAI 兼容 API 接入企业本地系统
curl http://localhost:11434/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
        "model": "deepseek-r1:7b",
        "messages": [{"role": "user", "content": "请用 Python 写一个支持重试的 Redis 分布式锁"}],
        "stream": true
    }'
```
