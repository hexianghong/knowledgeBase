# MySQL 数据库巡检报告与运维管理规范

定期巡检是保障 MySQL 数据库高可用与稳定运行的重要预防性维护手段。通过主动排查系统配置、磁盘空间、数据库锁、慢查询、备份有效性以及安全弱口令，能最大程度防患于未然。

---

## 1. 数据库日常巡检 Checklist

在日常运维中，DBA 或系统运维人员应定期（如每周或每月）对以下关键指标进行体检：

| 巡检维度 | 核心检查项 | 预警阈值与标准 |
| :--- | :--- | :--- |
| **系统资源** | CPU 使用率、系统负载、内存剩余、网卡丢包情况。 | CPU / MEM 使用率 > 90% 预警。 |
| **磁盘空间** | 数据目录（`datadir`）、归档日志（`binlog`）及临时文件目录的磁盘空间使用率。 | 磁盘分区空间使用率 > 85% 预警。 |
| **连接与并发** | 当前并发连接数、历史最大连接数、空闲（`Sleep`）连接堆积情况。 | 历史最大连接 / `max_connections` > 80% 预警。 |
| **表与索引健康** | 非 InnoDB 引擎表、表容量 TOP 10、高碎片率表、无主键大表、冗余索引和未使用的索引。 | • 无主键大表限制。<br>• 表碎片率 > 70% 建议重建（`OPTIMIZE`）。 |
| **安全审计** | 弱口令账号、账号密码相同、用户为空的匿名账号、拥有 `SUPER` 权限的非 `root` 账号。 | 严禁弱口令与 `%` 白名单滥用。 |
| **日志与慢 SQL** | 错误日志（`error_log`）中的 ERROR 警告、慢查询日志（`slow_log`）的慢 SQL 统计。 | 对执行频次高、耗时长的 SQL 进行定期治理。 |
| **高可用与备份** | 主从同步延迟（`Seconds_Behind_Master`）、MGR 成员状态、备份集完整性及最近一次恢复演练。 | 主从延迟严重、备份缺失报错必须即时干预。 |

## 2. MySQL 5.7 vs MySQL 8.0 巡检指令与系统视图适配对照

在编写自动化巡检工具或执行人工诊断时，必须根据 MySQL 大版本选用兼容的指令与系统表：

| 巡检诊断维度 | MySQL 5.7 检查指令 / 视图 | MySQL 8.0+ 检查指令 / 视图 | 适配说明与差异 |
| :--- | :--- | :--- | :--- |
| **主从复制状态** | `SHOW SLAVE STATUS\G` | `SHOW REPLICA STATUS\G` (兼容 `SHOW SLAVE STATUS`) | 8.0 推荐现代术语，8.4 LTS 废弃 SLAVE 指令 |
| **事务锁与等待排查** | `information_schema.innodb_locks`<br>`information_schema.innodb_lock_waits` | `performance_schema.data_locks`<br>`performance_schema.data_lock_waits` | 8.0 移除旧版 innodb_locks，改由 Performance Schema 提供 |
| **用户与认证插件检测** | `SELECT user, host, plugin FROM mysql.user` (默认 `mysql_native_password`) | `SELECT user, host, plugin, account_locked, password_expired FROM mysql.user` (默认 `caching_sha2_password`) | 8.0 增加密码过期与锁定状态字段 |
| **持久化参数配置检查** | 无 (需比对 `my.cnf` 文件) | `SELECT * FROM performance_schema.persisted_variables` | 检查 `SET PERSIST` 动态写入的持久化参数 |
| **自增 ID 溢出风险探测** | 查询 `information_schema.tables.AUTO_INCREMENT` | 查询 `information_schema.tables.AUTO_INCREMENT` (结合 `SHOW CREATE TABLE`) | 8.0 自增计数器变更已写入 Redo Log 持久化 |
| **优化器直方图元数据** | 无 | `SELECT * FROM information_schema.column_statistics` | 检查是否有倾斜列直方图需更新统计信息 |

## 3. 自动化巡检脚本使用指南

本工具是一个简易的 Shell 本机巡检脚本，能够一键获取系统基础信息、磁盘使用率、库表容量统计、无主键大表检测、安全弱口令排查及日志统计，并直接生成一份易读的 Markdown 格式巡检报告。

### 运行说明
1.  建议将脚本上传至数据库服务器的临时目录（如 `/tmp/`）。
2.  执行时需要提供连接 MySQL 的用户名、密码及端口。
3.  **注意**：由于脚本需要查询 `information_schema` 等系统视图，对大库执行时会产生短时的 CPU 开销，**建议在业务低峰期执行**。

```bash
# 运行命令示例
sh mysql_inspection.sh -h 127.0.0.1 -P 3306 -u root -p 'yourpassword'

# 开启详情模式运行
sh mysql_inspection.sh -h 127.0.0.1 -P 3306 -u root -p 'yourpassword' --detail
```
*   **报告输出**：运行结束后，将在 `/tmp/` 目录下生成类似 `ddcw_inspection_[hostname]_[datetime].md` 的巡检报告。

## 3. 自动化巡检脚本代码 (mysql_inspection.sh)

```bash
#!/usr/bin/env bash
# write by ddcw @https://github.com/ddcw/inspection
# mysql巡检脚本 . 仅支持本机巡检.

source /etc/profile
export LANG="en_US.UTF-8"
stty erase ^H
 
MDFILENAME="/tmp/ddcw_inspection_`hostname`_$(date '+%Y%m%d_%H%M%S').md"
START_DATETIME="`date '+%Y:%m:%d %H:%M:%S'`"
MYSQL_COM="mysql"
MYSQL_BIN="mysql"
MYSQL_COM_COMMENT="${MYSQL_COM}"
HELP_FLAG=false
PARAMS=$@
HOSTNAME=`hostname`
PORT=3306
SUGGESTION=""
SUMMARY=""
REQUIRE_PASSWORD=true
SHOW_DETAIL=false
 
# 添加建议信息
add_suggestion(){
    SUGGESTION="${SUGGESTION}${@}\n"
}
 
# 添加汇总信息
add_summary(){
    SUMMARY="${SUMMARY}\n${@}"
}
 
# 使用mysql来做数字比较计算
sql_com(){
    sql=$1
    value=$2
    [ -z ${value} ] && value=1
    if [ "`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`" == "${value}" ];then
        return 0
    else
        return 1
    fi
}
 
exit1(){
    echo "[`date "+%Y-%m-%d %H:%M:%S"]` [ERROR] ${@}"
    exit 1
}
 
# 输出日志
log(){
    _msg="[$(date '+%Y-%m-%d %H:%M:%S')] [INFO] $@"
    echo -e ${_msg} >&2
}
 
# 写入 Markdown 表格结构
TMD(){
    title_level=$1 
    title_name=$2  
    header=$3      
    value=$4       
    echo -e "\n$(printf '%*s' ${title_level}'' | tr ' ' '#') ${title_name}" >> ${MDFILENAME}
    add_summary "\n\n############ ${title_name} #########"
    if [ "${value}" == "" ];then
        echo "无" >> ${MDFILENAME}
        add_summary "无\n"
    else
        echo -e "${header}" >> ${MDFILENAME}
        echo -e "${header}" | sed 's/[^|]/-/g' >> ${MDFILENAME}
        echo "${value}" | sed 's/\t/ | /g;s/^/| /;s/$/ |/' >> ${MDFILENAME}
        add_summary "${header}\n${value}"
    fi
}
 
# 写入普通文本内容
HTMD(){
    title_level=$1
    title_name=$2
    msg=$3
    echo -e "\n$(printf '%*s' ${title_level}'' | tr ' ' '#') ${title_name}" >> ${MDFILENAME}
    echo -e "\n${msg}\n" >> ${MDFILENAME}
}
 
# 参数解析与初始化
params_init(){
    SHORT_OPTS="h:P:u:p:m:S:l:H:d"
    LONG_OPTS="host:,port:,user:,password:,mysql:,socket:,login-path:,help:,detail"
    PARSED_OPTS=$(getopt -o "$SHORT_OPTS" --long "$LONG_OPTS" --name "$0" -- "$@")
    MYSQL_COM=""
    MYSQL_COM_COMMENT=""
    if [[ $? -ne 0 ]]; then
        exit 2
    fi
    eval set -- "$PARSED_OPTS"
     
    while true; do
        case "$1" in
            -h|--host)
                MYSQL_COM="${MYSQL_COM} --host $2"
                MYSQL_COM_COMMENT="${MYSQL_COM_COMMENT} --host $2"
                HOSTNAME="$2"
                shift 2
                ;;
            -P|--port)
                MYSQL_COM="${MYSQL_COM} --port $2"
                MYSQL_COM_COMMENT="${MYSQL_COM_COMMENT} --port $2"
                PORT=$2
                shift 2
                ;;
            -u|--user)
                MYSQL_COM="${MYSQL_COM} --user $2"
                MYSQL_COM_COMMENT="${MYSQL_COM_COMMENT} --user $2"
                shift 2
                ;;
            -p|--password)
                MYSQL_COM="${MYSQL_COM} -p$2"
                MYSQL_COM_COMMENT="${MYSQL_COM_COMMENT} -p******"
                shift 2
                ;;
            -S|-s|--socket)
                MYSQL_COM="${MYSQL_COM} --socket $2"
                MYSQL_COM_COMMENT="${MYSQL_COM_COMMENT} --socket $2"
                shift 2
                ;;
            -l|--login-path)
                MYSQL_COM="${MYSQL_COM} --login-path=$2"
                MYSQL_COM_COMMENT="${MYSQL_COM_COMMENT} --login-path=$2"
                shift 2
                ;;
            -m|--mysql)
                MYSQL_BIN="$2"
                shift 2
                ;;
            -H|--help)
                HELP_FLAG=true
                shift 1
                ;;
            -d|--detail)
                SHOW_DETAIL=true
                shift 1
                ;;
            --|-)
                shift
                break
                ;;
            *)
                echo "参数有误. 请运行 --help ."
                exit 3
                ;;
        esac
    done
    MYSQL_COM="${MYSQL_BIN} ${MYSQL_COM}"
    MYSQL_COM_COMMENT="${MYSQL_BIN} ${MYSQL_COM_COMMENT}"
}
 
help_this(){
    cat << EOF
MySQL 巡检脚本使用指南:
    --host       连接的数据库 IP 地址
    --port       数据库连接端口 (默认 3306)
    --user       数据库连接用户名
    --password   密码
    --socket     指定 Socket 文件
    --login-path login-path-name
    --mysql      mysql 客户端命令物理路径，例如: /usr/bin/mysql
    --help       打印帮助信息
    --detail     控制台显示详情
 
示例:
    sh $0 -h127.0.0.1 -P3306 -uroot -p123456
EOF
    exit 0
}
 
# 校验数据库连接与执行权限
check_pre(){
    if ${MYSQL_COM} -e 'select 1+1' >/dev/null 2>&1;then
        log "${MYSQL_COM_COMMENT} Connect Success"
    else
        exit1 "${MYSQL_COM_COMMENT} Connect Failed!!!"
    fi
 
    if ${MYSQL_COM} -e 'select * from sys.memory_global_total;' >/dev/null 2>&1 && ${MYSQL_COM} -e 'show slave status;' >/dev/null 2>&1; then
        log "Privileges OK"
    else
        exit1 "MySQL 执行权限不足，请使用具有 system_variables/sys 库查询及 Show slave status 权限的账号运行"
    fi
}
 
# 获取操作系统及 MySQL 基础配置信息
i_baseinfo(){
    log "GET BASE INFO"
    log "GET HOST CPU INFO"
    cpu_socket=$(lscpu | awk -F ':' '{if ($1=="Socket(s)") print $2}' | awk '{print $1}')
    cpu_cores=$(lscpu | awk -F ':' '{if ($1=="Core(s) per socket") print $2}' | awk '{print $1}')
    cpu_thread=$(lscpu | awk -F ':' '{if ($1=="Thread(s) per core") print $2}' | awk '{print $1}')
    cpu_type=$(lscpu | awk -F ':' '{if ($1=="Model name") print $2}' | sed 's/^\s*//g')
 
    log "GET HOST MEM INFO"
    mem_total=$(grep 'MemTotal' /proc/meminfo  | awk '{print $2}')
    mem_free=$(grep 'MemFree' /proc/meminfo  | awk '{print $2}')
    mem_available=$(grep 'MemAvailable' /proc/meminfo  | awk '{print $2}')
    swap_total=$(grep 'SwapTotal' /proc/meminfo  | awk '{print $2}')
    swap_available=$(grep 'SwapFree' /proc/meminfo  | awk '{print $2}')
     
    mysql_status="`${MYSQL_COM} -NB -e 'status' 2>/dev/null`"
    msg="INSPECTION DATETIME\t${START_DATETIME}"
    msg="${msg}\nHOSTNAME\t${HOSTNAME}\nPORT\t${PORT}\nUPTIME\t`uptime | awk -F ',' '{print $1}'`\nLOAD\t`uptime | awk -F ',' '{print $(NF-2)$(NF-1)$NF}' | awk -F ':' '{print $NF}'`"
    msg="${msg}\nCPU_TYPE\t${cpu_type}\nCPU\t${cpu_socket} * ${cpu_cores} * ${cpu_thread} = $[ ${cpu_socket} * ${cpu_cores} * ${cpu_thread} ]"
    msg="${msg}\nMEM\t $[ ${mem_available} / 1024 ] MB / $[ ${mem_total} / 1024 ] MB"
    msg="${msg}\nSWAPPINESS\t`cat /proc/sys/vm/swappiness`"
    msg="${msg}\nMYSQL CLIENT VERSION\t`${MYSQL_BIN} --version --verbose`"
    server_version="`${MYSQL_COM} -NB -e 'select @@version;' 2>/dev/null`"
    msg="${msg}\nMYSQL SERVER VERSION\t${server_version}"
    msg="${msg}\nMYSQL UPTIME\t`echo -e \"${mysql_status}\" | awk '{if ($1==\"Uptime:\") {$1=\"\"; print $0}}'` (`${MYSQL_COM} -NB -e \"show global status like 'uptime';\" 2>/dev/null | awk '{print $NF}'` s)"
    
    log "GET MYSQL INNODB_BUFFER_POOL"
    innodb_buffer_pool_size_gb=`${MYSQL_COM} -NB -e 'select round(@@innodb_buffer_pool_size/1024/1024/1024,2);' 2>/dev/null`
    innodb_buffer_pool_hitrate=`${MYSQL_COM} -NB -e 'select round(avg(HIT_RATE)/10,2) from information_schema.INNODB_BUFFER_POOL_STATS;' 2>/dev/null`
    innodb_buffer_pool_used=`${MYSQL_COM} -NB -e 'select round(sum(FREE_BUFFERS)/sum(POOL_SIZE)*100,2) from information_schema.INNODB_BUFFER_POOL_STATS;' 2>/dev/null`
    msg="${msg}\nINNODB BUFFER POOL SIZE\t${innodb_buffer_pool_size_gb} GB"
    msg="${msg}\nINNODB BUFFER POOL HIT RATE\t${innodb_buffer_pool_hitrate} %"
    msg="${msg}\nINNODB BUFFER POOL USED\t${innodb_buffer_pool_used} %"
    
    log "GET MYSQL CONNECTION"
    current_connect=`${MYSQL_COM} -NB -e "show global status like 'Threads_connected';" 2>/dev/null | awk '{print $NF}'`
    connect_var=`${MYSQL_COM} -NB -e "select @@max_connections;" 2>/dev/null | awk '{print $NF}'`
    max_connect=`${MYSQL_COM} -NB -e "show global status like 'Max_used_connections';" 2>/dev/null | awk '{print $NF}'`
    msg="${msg}\nCONNECTION\t${current_connect}/${connect_var}"
    msg="${msg}\nMAX_CONNECTION\t${max_connect}/${connect_var}"
    msg="${msg}\nDATABASE COUNT\t`${MYSQL_COM} -NB -e \"select count(*) from information_schema.SCHEMATA where SCHEMA_NAME not in ('sys','performance_schema','mysql','information_schema');\" 2>/dev/null` ( `${MYSQL_COM} -NB -e \"select round(sum(data_length)/1024/1024/1024,2) from information_schema.tables where table_schema not in ('sys','performance_schema','mysql','information_schema');\" 2>/dev/null` GB)"
    msg="${msg}\nTABLE COUNT\t`${MYSQL_COM} -NB -e \"select count(*) from information_schema.tables where table_schema not in ('sys','performance_schema','mysql','information_schema');\" 2>/dev/null`"
 
    if [ "`echo \"${server_version}\" | grep -o '\b[0-9]\+\b' | head -2 | tr '\n' ' '`" == "5 7 " ];then
        if [ `echo "${server_version}" | grep -o '\b[0-9]\+\b' | tail -1` -lt 44 ];then
            add_suggestion "当前 MySQL 版本为: ${server_version} , 低于推荐安全线 5.7.44，存在安全漏洞及已知 Bug 风险，建议排期升级。"
        fi
    fi
    sql_com "select ${innodb_buffer_pool_hitrate} < 99.5" 1 && add_suggestion "当前 InnoDB Buffer Pool 读物理缓存命中率较低(${innodb_buffer_pool_hitrate}% < 99.5%), 说明物理 I/O 频繁，建议扩充主机内存并增大缓冲池大小。"
    sql_com "select ${max_connect}/${connect_var} > 0.75" 1 && add_suggestion "历史最大并发连接数占比极高(${max_connect}/${connect_var})，已逼近 max_connections 设定。建议调大 max_connections 并排查应用连接池。"
    TMD 1 "基础信息" "|对象|值|" "`echo -e \"${msg}\"`"
 
    # 文件系统剩余空间检查
    msg=""
    datadir="`${MYSQL_COM} -NB -e \"select @@datadir\" 2>/dev/null`"
    msg="datadir\t${datadir}\t`df -hPT ${datadir} | tail -1 | awk '{print $1\"\t\"$2\"\t\"$3\"\t\"$4\"\t\"$5\"\t\"$6\"\t\"$7}' `"
    usage_persent=`df -hPT ${datadir} | awk '{sub(/\%/," "); if ($(NF-1) >  90) print $(NF-1)}'  | tail -n +2 `
    [ "${usage_persent}" == "" ] || add_suggestion "数据目录分区 ${datadir} 使用率已超过 90% (当前使用率:${usage_persent}%). 磁盘有写满风险，请尽快扩容或清理无用日志！"
 
    sql="SELECT CASE WHEN @@log_bin_basename is null THEN @@datadir WHEN LEFT(@@log_bin_basename, 1) = '/' THEN @@log_bin_basename ELSE CONCAT(@@datadir, @@log_bin_basename) END AS result_path;"
    binlogdir="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    msg="${msg}\nbinlogdir\t${binlogdir}\t`df -hPT ${binlogdir%/*} | tail -1 | awk '{print $1\"\t\"$2\"\t\"$3\"\t\"$4\"\t\"$5\"\t\"$6\"\t\"$7}' `"
    usage_persent=`df -hPT ${binlogdir%/*} | awk '{sub(/\%/," "); if ($(NF-1) >  90) print $(NF-1)}'  | tail -n +2 `
    [ "${usage_persent}" == "" ] || add_suggestion "Binlog 目录分区 ${binlogdir%/*} 使用率超过 90% (当前使用率:${usage_persent}%). 请调整 Binlog 过期天数。"
 
    sql="SELECT CASE WHEN @@innodb_log_group_home_dir is null THEN @@datadir WHEN LEFT(@@innodb_log_group_home_dir, 1) = '/' THEN @@innodb_log_group_home_dir ELSE CONCAT(@@datadir, @@innodb_log_group_home_dir) END AS result_path;"
    redologdir="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    msg="${msg}\nredologdir\t${redologdir}\t`df -hPT ${redologdir} | tail -1 | awk '{print $1\"\t\"$2\"\t\"$3\"\t\"$4\"\t\"$5\"\t\"$6\"\t\"$7}' `"
    usage_persent=`df -hPT ${redologdir} | awk '{sub(/\%/," "); if ($(NF-1) >  90) print $(NF-1)}'  | tail -n +2 `
    [ "${usage_persent}" == "" ] || add_suggestion "Redo Log 目录分区 ${redologdir} 使用率超过 90% (当前使用率:${usage_persent}%)."
 
    sql="SELECT CASE WHEN @@tmpdir is null THEN @@datadir WHEN LEFT(@@tmpdir, 1) = '/' THEN @@tmpdir ELSE CONCAT(@@datadir, @@tmpdir) END AS result_path;"
    tmpdir="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    msg="${msg}\ntmpdir\t${tmpdir}\t`df -hPT ${tmpdir} | tail -1 | awk '{print $1\"\t\"$2\"\t\"$3\"\t\"$4\"\t\"$5\"\t\"$6\"\t\"$7}' `"
    usage_persent=`df -hPT ${tmpdir} | awk '{sub(/\%/," "); if ($(NF-1) >  90) print $(NF-1)}'  | tail -n +2 `
    [ "${usage_persent}" == "" ] || add_suggestion "临时目录 ${tmpdir} 使用率超过 90% (当前使用率:${usage_persent}%). 防止大查询产生大量临时文件导致磁盘满。"
     
    TMD 0 "文件系统信息" "|对象|目录名|文件系统|类型|总大小|使用大小|可用大小|使用率|挂载点|" "`echo -e \"${msg}\"`"
}
 
# 检查数据库大小和字符集
i_check_database(){
    log "GET DATABASE INFO"
    sql="SELECT a.table_schema, ROUND(SUM(a.data_length) / 1024 / 1024 / 1024, 2) AS data_length_GB, ROUND(SUM(a.index_length / 1024 / 1024 / 1024), 2) AS index_length_GB, ROUND(SUM(a.data_free / 1024 / 1024 / 1024), 2) AS data_free_GB, b.DEFAULT_CHARACTER_SET_NAME, b.DEFAULT_COLLATION_NAME FROM information_schema.tables AS a join information_schema.schemata AS b WHERE a.table_schema = b.SCHEMA_NAME AND a.table_schema NOT IN ('sys' , 'information_schema', 'performance_schema', 'mysql') GROUP BY a.table_schema,b.DEFAULT_CHARACTER_SET_NAME,b.DEFAULT_COLLATION_NAME ORDER BY 2 DESC"
    msg="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    TMD 2 "数据库大小" "|数据库名字|数据大小(GB)|索引大小(GB)|碎片大小(GB)|默认字符集|默认排序规则|" "`echo -e \"${msg}\"`"
}
 
# 检查大表、非 InnoDB 表、高碎片率表
i_check_table(){
    log "GET TABLE INFO"
    log "GET TOP10 TABLE"
    sql="SELECT table_schema, table_name, TABLE_ROWS, ROUND(data_length / 1024 / 1024 / 1024, 2) AS data_length_GB, ROUND(index_length / 1024 / 1024 / 1024, 2) AS index_free_GB, ROUND(data_free / 1024 / 1024 / 1024, 2) AS data_free_GB FROM information_schema.tables WHERE table_schema NOT IN ('sys' , 'information_schema', 'performance_schema', 'mysql') ORDER BY 4 DESC LIMIT 10;"
    msg="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    TMD 2 "TOP10 表" "|数据库名|表名|行数|数据大小(GB)|索引大小(GB)|碎片大小(GB)|" "`echo -e \"${msg}\"`"
     
    # 检查非 InnoDB 存储引擎表
    msg="`${MYSQL_COM} -NB -e \"select TABLE_SCHEMA,TABLE_NAME,ENGINE from information_schema.tables where ENGINE != 'InnoDB' and TABLE_SCHEMA not in ('sys','information_schema','mysql','performance_schema');\" 2>/dev/null`"
    TMD 2 "非 INNODB 表" "|数据库名|表名|存储引擎|" "`echo -e \"${msg}\"`"
    [ "${msg}" == "" ] || add_suggestion "检测到当前实例中包含有 `echo -e \"${msg}\" | wc -l` 张非 InnoDB 表。为了保障数据事务安全，建议统一修改存储引擎为 InnoDB (ALTER TABLE 表名 ENGINE=InnoDB)。"
 
    # 检查碎片率高的表（行数超 100 万且碎片占比超 70%）
    log "GET fragmented table"
    sql="SELECT * FROM (SELECT TABLE_SCHEMA, TABLE_NAME, TABLE_ROWS, round(data_length/1024/1024/1024,2) as data_length_GB, round(data_free/1024/1024/1024,2) as data_free_GB, ROUND(DATA_FREE / (DATA_LENGTH + DATA_FREE) * 100, 2) AS fragment_rate FROM information_schema.tables WHERE DATA_LENGTH > 0 and TABLE_ROWS > 1000000 AND TABLE_SCHEMA NOT IN ('sys' , 'information_schema', 'mysql', 'performance_schema')) AS aa WHERE aa.fragment_rate > 70 order by aa.fragment_rate desc;"
    msg="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    TMD 2 "碎片表" "|数据库名|表名|数据行数|数据大小(GB)|碎片大小(GB)|碎片率(%)|" "`echo -e \"${msg}\"`"
    [ "${msg}" == "" ] || add_suggestion "存在 `echo -e \"${msg}\" | wc -l` 张高碎片率（>70%）的大数据表。建议在业务低峰期执行优化命令重建表，释放表空间物理碎片 (OPTIMIZE TABLE 表名)。"
}
 
# 检查索引异常（无主键、未使用的索引、冗余索引）
i_check_index(){
    # 检查无主键大表 (行数 >= 50 万)
    log "GET NO PK TABLE"
    sql="SELECT t.table_schema, t.table_name, t.table_rows, round(t.data_length/1024/1024/1024,2),CREATE_TIME FROM information_schema.tables t LEFT JOIN information_schema.table_constraints tc ON t.table_schema = tc.table_schema AND t.table_name = tc.table_name AND tc.constraint_type = 'PRIMARY KEY' WHERE t.table_schema NOT IN ('mysql' , 'information_schema', 'performance_schema', 'sys') AND tc.constraint_name IS NULL AND t.table_type = 'BASE TABLE' and t.table_rows >= 500000;"
    msg="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    TMD 2 "无主键的表" "|数据库名|表名|数据行数|数据大小(GB)|表创建时间|" "`echo -e \"${msg}\"`"
    [ "${msg}" == "" ] || add_suggestion "发现有 `echo -e \"${msg}\" | wc -l` 张大表（>= 50万行）无主键约束。在主从复制和 MGR 下会产生严重性能瓶颈，建议尽快添加主键自增 ID。"
 
    # 检查未使用的索引 (uptime需大于30天)
    mysql_uptime="`${MYSQL_COM} -NB -e \"show global status like 'uptime';\" 2>/dev/null | awk '{print $NF}'`"
    greate_tiem=$[ 30 * 24 * 3600 ]
    if [ ${mysql_uptime} -ge ${greate_tiem} ];then
        log "GET NO USED INDEX"
        sql="select object_schema,object_name,index_name from sys.schema_unused_indexes where object_schema not in ('mysql' , 'information_schema', 'performance_schema','sys');"
        msg="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
        TMD 2 "未使用的索引" "|数据库名|表名|索引名|" "`echo -e \"${msg}\"`"
        [ "${msg}" == "" ] || add_suggestion "当前实例运行超过30天，检测到 `echo -e \"${msg}\" | wc -l` 个未被业务使用的冗余索引。为加速插入写速度并节约磁盘空间，建议评估后予以删除。"
    fi
 
    # 检查完全无任何索引的表
    log "GET NO INDEX TABLE"
    sql="SELECT t.TABLE_SCHEMA, t.TABLE_NAME FROM information_schema.TABLES t LEFT JOIN information_schema.STATISTICS s ON t.TABLE_SCHEMA = s.TABLE_SCHEMA AND t.TABLE_NAME = s.TABLE_NAME WHERE t.TABLE_SCHEMA NOT IN ('information_schema' , 'mysql', 'performance_schema', 'sys') GROUP BY t.TABLE_SCHEMA , t.TABLE_NAME HAVING COUNT(s.INDEX_NAME) = 0;"
    msg="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    TMD 2 "无索引的表" "|数据库名|表名|" "`echo -e \"${msg}\"`"
    [ "${msg}" == "" ] || add_suggestion "存在 `echo -e \"${msg}\" | wc -l` 张没有任何索引的表，此类表在关联查询时极易导致全表扫描，建议根据查询需要建立索引。"
 
    # 检查冗余重叠索引
    log "GET redundant_indexes"
    sql="select table_schema,table_name,dominant_index_name,dominant_index_columns,redundant_index_name,redundant_index_columns,sql_drop_index from sys.schema_redundant_indexes"
    msg="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    TMD 2 "冗余索引" "|数据库名|表名|主索引名|主索引字段|冗余索引名|冗余索引字段|建议SQL|" "`echo -e \"${msg}\"`"
    [ "${msg}" == "" ] || add_suggestion "存在 `echo -e \"${msg}\" | wc -l` 处冗余索引。例如，(a,b) 联合索引已覆盖 (a) 单列索引，建议执行建议 SQL 清理。"
}
 
# 检查账号安全（弱口令、共享密码、超级权限）
i_check_user(){
    # 密码相同的账号
    log "GET SAME PASSWORD FOR ACCOUNT"
    sql="SELECT '*****' as password, GROUP_CONCAT(CONCAT(user, '@', host) SEPARATOR ', ') AS user_hosts FROM mysql.user WHERE authentication_string <> '' AND user NOT IN ('mysql.sys' , 'mysql.session', 'mysql.infoschema') GROUP BY authentication_string HAVING COUNT(*) > 1;"
    msg="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    TMD 2 "密码相同的账号" "|密码(脱敏)|账号|" "`echo -e \"${msg}\"`"
    [ "${msg}" == "" ] || add_suggestion "检测到多个账号配置了完全相同的加密哈希密码，建议实现账号密码分离管理。"
 
    # 弱口令检查 (与用户名相同、空口令或常用弱密码)
    password_dic="123456 123 1234 12345678 admin abc123 qwerty P@ssw0rd mysql root password 1234567890" 
    sql="SELECT CONCAT(user, '@', host) as account FROM mysql.user where authentication_string = CONCAT('*', UPPER(SHA1(UNHEX(SHA1(user)))))"
    msg="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    for password in ${password_dic}; do
        tmpsql="SELECT CONCAT(user, '@', host) as account FROM mysql.user where authentication_string = CONCAT('*', UPPER(SHA1(UNHEX(SHA1('${password}')))));"
        tmpmsg="`${MYSQL_COM} -NB -e \"${tmpsql}\" 2>/dev/null`"
        [ "${tmpmsg}" == "" ] || msg="${msg}\n${tmpmsg}"
    done
    TMD 2 "弱口令账号" "|弱口令账号|" "`echo -e \"${msg}\"`"
    [ "${msg}" == "" ] || add_suggestion "警告！检测到有 `echo -e \"${msg}\" | wc -l` 个账号配置了极高危的弱口令。请立即修改密码！"
 
    # 用户名为空的匿名账号
    nulluser="`${MYSQL_COM} -NB -e \"select concat(user,'@',host) from mysql.user where user='';\" 2>/dev/null`"
    if [ "${nulluser}" != "" ];then
        TMD 2 "用户名为空的账号" "|用户名为空的账号|" "`echo -e \"${nulluser}\"`"
        add_suggestion "存在用户名为空的匿名可访问账号。极易遭受本地匿名入侵风险，建议执行 DROP USER 予以删除。"
    fi
 
    # 拥有超级权限 (SUPER) 的非 root 账号
    sql="select concat(user,'@',host) from mysql.user where user not in ('root','mysql.session') and Super_priv='Y';"
    msg="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    TMD 2 "Super权限的账号" "|有Super权限的账号|" "`echo -e \"${msg}\"`"
    [ "${msg}" == "" ] || add_suggestion "检测到非 root 普通应用账号拥有 `SUPER` 超级管理权限，存在误更新参数等重大安全隐患，建议撤销超级权限。"
}
 
# 监控 InnoDB 状态与全局状态参数
i_check_innodb(){
    msg=""
    Innodb_buffer_pool_read_requests="`${MYSQL_COM} -NB -e \"show global status like 'Innodb_buffer_pool_read_requests';\" 2>/dev/null | awk '{print $NF}'`" 
    Innodb_buffer_pool_reads="`${MYSQL_COM} -NB -e \"show global status like 'Innodb_buffer_pool_reads';\" 2>/dev/null | awk '{print $NF}'`" 
    Innodb_read_hits="`${MYSQL_COM} -NB -e \"select round(${Innodb_buffer_pool_read_requests}/(${Innodb_buffer_pool_read_requests}+${Innodb_buffer_pool_reads})*100,2)\" 2>/dev/null`"
    if [ "`${MYSQL_COM} -NB -e \"select ${Innodb_read_hits} < 99.5\" 2>/dev/null`" == "1" ];then
        if [ "`${MYSQL_COM} -NB -e \"select ${Innodb_read_hits} > 95.0\" 2>/dev/null`" == "1" ];then
            add_suggestion "Innodb 读缓冲命中率下降至: ${Innodb_read_hits}%. 物理 I/O 读已增加，建议排查慢查询或增大缓冲池。"
            msg="${msg}innodb读命中率\t${Innodb_read_hits}%\t警告：缓存命中轻微下降\n"
        else
            add_suggestion "高危！Innodb 读物理命中率低至: ${Innodb_read_hits}%. 会引发磁盘 I/O 拥堵，数据库即将假死！"
            msg="${msg}innodb读命中率\t${Innodb_read_hits}%\t高危：缓存未命中严重\n"
        fi
    else
        msg="${msg}innodb读命中率\t${Innodb_read_hits}%\t正常 (>=99.5%)\n"
    fi
 
    # table open cache 命中率
    Table_open_cache_hits="`${MYSQL_COM} -NB -e \"show global status like 'Table_open_cache_hits';\" 2>/dev/null | awk '{print $NF}'`" 
    Table_open_cache_misses="`${MYSQL_COM} -NB -e \"show global status like 'Table_open_cache_misses';\" 2>/dev/null | awk '{print $NF}'`" 
    Table_open_cache_hit="`${MYSQL_COM} -NB -e \"select round(${Table_open_cache_hits}/(${Table_open_cache_hits}+${Table_open_cache_misses})*100,2)\" 2>/dev/null`"
    msg="${msg}Table_open_cache_hit\t${Table_open_cache_hit}%\t表元数据缓存命中率\n"
 
    # redo log 等待频次
    log_waits="`${MYSQL_COM} -NB -e\"show global status like 'Innodb_log_waits';\" 2>/dev/null | awk '{print $NF}'`"
    msg="${msg}innodb日志等待\t${log_waits}\t重做日志缓存等待(由于 innodb_log_buffer_size 不足)\n"
    [ "${log_waits}" -eq 0 ] || add_suggestion "检测到重做日志写盘等待 (Innodb_log_waits = ${log_waits})，说明 Redo Log 缓存小或磁盘写过慢，建议增加 innodb_log_buffer_size。"
 
    # 读写比例
    Innodb_rows_read="`${MYSQL_COM} -NB -e \"show global status like 'Innodb_rows_read';\" 2>/dev/null | awk '{print $NF}'`"
    Innodb_rows_inserted="`${MYSQL_COM} -NB -e \"show global status like 'Innodb_rows_inserted';\" 2>/dev/null | awk '{print $NF}'`"
    Innodb_rows_deleted="`${MYSQL_COM} -NB -e \"show global status like 'Innodb_rows_deleted';\" 2>/dev/null | awk '{print $NF}'`"
    Innodb_rows_updated="`${MYSQL_COM} -NB -e \"show global status like 'Innodb_rows_updated';\" 2>/dev/null | awk '{print $NF}'`"
    Innodb_rows_rw_rate="`${MYSQL_COM} -NB -e \"select round(${Innodb_rows_read}/(0.001+${Innodb_rows_inserted}+${Innodb_rows_deleted}+${Innodb_rows_updated})*100,2)\" 2>/dev/null`"
    msg="${msg}innodb读写比\t${Innodb_rows_rw_rate}%\tread:${Innodb_rows_read}/insert:${Innodb_rows_inserted}/delete:${Innodb_rows_deleted}/update:${Innodb_rows_updated}\n"
 
    # 临时表磁盘化比例
    Created_tmp_disk_tables="`${MYSQL_COM} -NB -e \"show global status like 'Created_tmp_disk_tables';\" 2>/dev/null | awk '{print $NF}'`"
    Created_tmp_tables="`${MYSQL_COM} -NB -e \"show global status like 'Created_tmp_tables';\" 2>/dev/null | awk '{print $NF}'`"
    Created_tmp_table_disk_rate="`${MYSQL_COM} -NB -e \"select round(${Created_tmp_disk_tables}/(0.00001+${Created_tmp_tables})*10000,2)\" 2>/dev/null`"
    msg="${msg}磁盘临时表占比\t万分之 ${Created_tmp_table_disk_rate}\t内存临时表:${Created_tmp_tables}/磁盘临时表:${Created_tmp_disk_tables}\n"
    if [ "`${MYSQL_COM} -NB -e \"select ${Created_tmp_table_disk_rate} > 5\" 2>/dev/null`" == "1" ];then
        add_suggestion "临时表落盘比例偏高 (万分之${Created_tmp_table_disk_rate})。通常由大查询或未用索引的分组排序导致，建议优化 SQL 或增大 tmp_table_size。"
    fi
 
    # 慢查询占比
    Slow_queries="`${MYSQL_COM} -NB -e \"show global status like 'Slow_queries';\" 2>/dev/null | awk '{print $NF}'`"
    Questions="`${MYSQL_COM} -NB -e \"show global status like 'Questions';\" 2>/dev/null | awk '{print $NF}'`"
    Slow_queries_rate="`${MYSQL_COM} -NB -e \"select round((${Slow_queries}+0)/${Questions}*10000,2)\" 2>/dev/null`"
    msg="${msg}慢查询占比\t万分之 ${Slow_queries_rate}\t慢SQL:${Slow_queries}/总命令:${Questions}\n"
    if [ "`${MYSQL_COM} -NB -e \"select ${Slow_queries_rate} > 1\" 2>/dev/null`" == "1" ];then
        add_suggestion "慢查询占比偏高(万分之${Slow_queries_rate})，建议优化慢查询日志中的 SQL 以降本增效。"
    fi
 
    # Performance Schema 内存占用
    psmem=`${MYSQL_COM} -NB -e "SHOW ENGINE PERFORMANCE_SCHEMA STATUS;" 2>/dev/null | awk '{if ($2=="performance_schema.memory") {printf "%.2fMB" , $NF/1024/1024}}'`
    msg="${msg}performance内存\t${psmem}\tperformance_schema组件内存开销"
 
    TMD 2 "状态" "|对象|值|描述|" "`echo -e \"${msg}\"`"
}

# 检查错误日志并拉取最新 ERROR 警报
i_check_error_log(){
    sql="SELECT CASE WHEN @@log_error is null THEN @@datadir WHEN LEFT(@@log_error, 1) = '/' THEN @@log_error ELSE CONCAT(@@datadir, @@log_error) END AS result_path;"
    errorlog="`${MYSQL_COM} -NB -e \"${sql}\" 2>/dev/null`"
    versionlist=`grep 'Version: ' ${errorlog} | awk -F 'Version:' '{print $2}' | awk -F "'" '{print $2}' | sed '/^$/d' | uniq -c`

        add_suggestion "检测到错误日志中包含有数据库升级/重启历史记录: ${versionlist}"

    errorloglist=`tail -2000 ${errorlog} | grep '[ERROR]' | tail -10`

    fi
}
```

### 4.6 库表存储容量、表行数与碎片统计 (大盘扫描)
> **注意**：此类 SQL 在大库执行会带来磁盘 IO 和字典扫描开销，必须在**业务低峰期或定时巡检任务**中执行。

```sql
-- 11. 按 Schema 统计数据库总大小与总预估行数
SELECT 
  table_schema, 
  ROUND(SUM(data_length + index_length) / 1024 / 1024, 2) AS data_total_mb, 
  SUM(TABLE_ROWS) AS table_rows_sum 
FROM information_schema.tables 
WHERE TABLE_SCHEMA NOT IN ('information_schema', 'mysql', 'performance_schema', 'sys') 
GROUP BY table_schema 
ORDER BY data_total_mb DESC;

-- 12. 统计各库的表总数、平均单表大小
SELECT 
  table_schema, 
  COUNT(*) AS table_count, 
  ROUND(SUM(data_length + index_length) / 1024 / 1024, 2) AS data_total_mb, 
  SUM(TABLE_ROWS) AS table_rows_sum, 
  ROUND(AVG(data_length + index_length) / 1024 / 1024, 2) AS data_avg_mb 
FROM information_schema.tables 
WHERE TABLE_SCHEMA NOT IN ('information_schema', 'mysql', 'performance_schema', 'sys') 
GROUP BY table_schema 
ORDER BY table_count DESC;

-- 13. 全库单表物理总容量 TOP 排序 (含碎片空闲空间 data_free)
SELECT 
  TABLE_SCHEMA, 
  table_name, 
  ROUND(((data_length + index_length + data_free) / 1024 / 1024), 2) AS data_total_mb, 
  ROUND(((data_length) / 1024 / 1024), 2) AS data_length_mb, 
  ROUND(((index_length) / 1024 / 1024), 2) AS index_length_mb, 
  ROUND(((data_free) / 1024 / 1024), 2) AS data_free_mb, 
  TABLE_ROWS 
FROM information_schema.tables 
WHERE TABLE_SCHEMA NOT IN ('information_schema', 'performance_schema', 'mysql', 'sys') 
ORDER BY data_total_mb DESC;

-- 14. 碎片空间 TOP 排序 (用于制定 OPTIMIZE TABLE 或重建表计划)
SELECT 
  TABLE_SCHEMA, 
  table_name, 
  ROUND(((data_length + index_length + data_free) / 1024 / 1024), 2) AS data_total_mb, 
  ROUND(((data_free) / 1024 / 1024), 2) AS data_free_mb, 
  TABLE_ROWS 
FROM information_schema.tables 
WHERE TABLE_SCHEMA NOT IN ('information_schema', 'performance_schema', 'mysql', 'sys') 
ORDER BY data_free_mb DESC;

-- 15. 单表索引膨胀 TOP 排序 (检查索引是否超过数据本身大小)
SELECT 
  TABLE_SCHEMA, 
  table_name, 
  ROUND(((data_length) / 1024 / 1024), 2) AS data_length_mb, 
  ROUND(((index_length) / 1024 / 1024), 2) AS index_length_mb, 
  TABLE_ROWS 
FROM information_schema.tables 
WHERE TABLE_SCHEMA NOT IN ('information_schema', 'performance_schema', 'mysql', 'sys')

```

## 5. 架构认知对标：为什么巡检 SQL 不能直接作为 Prometheus Exporter 的高频采集项？

在 SRE 运维实践中，必须严格区分**“自动化周期巡检”**与**“Prometheus 时序监控抓取”**的边界：

| 对比维度 | 自动化周期巡检 (Inspection) | Prometheus mysqld-exporter 抓取 (Scraping) |
| :--- | :--- | :--- |
| **执行频次** | 每天 1 次、每周 1 次或故障时人工单次触发 | **每 15 秒或 30 秒高频轮询** |
| **执行时机** | 业务低峰期或凌晨进行 | 全天候 7x24 小时持续在线运行 |
| **资源容忍度** | 允许几秒至几十秒的单次查询耗时 | 必须在毫秒级内完成，超时（通常 >10s）即报错 |
| **表扫描 (tables)** | 允许一次性扫描 `information_schema.tables` 统计大表容量 | **5.7 下严禁高频执行**：无全局数据字典，会扫描所有 `.frm` 文件并争抢元数据锁 (MDL)，直接引发业务阻塞 |
| **会话排查 (processlist)** | 故障时查询 `information_schema.PROCESSLIST` 定位慢锁 | **5.7 下严禁高频执行**：需持有全局 `LOCK_thread_count` 互斥锁，高并发下导致业务无法新建连接 |
| **SQL 摘要 (eventsstatements)** | 巡检汇总慢 SQL 进行离线索引治理 | **严禁高频推送到 Prometheus**：Digest 基数极其庞大，会导致时序标签维度爆炸（High Cardinality）撑爆 Prometheus 内存 |
