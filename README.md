## 💡 知识库使用与维护规范

1. **绝对相对路径规范**：知识库内部所有文档引用、图片嵌入和跳转链接**严禁使用绝对路径**，必须使用可移植的项目级相对路径；
2. **网状互联与 0 死链**：编写任何专题技术文档时，需通过行内引用与章末 `> [!TIP] 💡 关联技术与延伸阅读` 建立闭环知识链；
3. **标准化沉淀**：新建专题、排障报告或变更 SOP 时，优先使用 [`./07_Templates/`](./07_Templates/) 目录下的标准模板。
