# 01_Research_Backlog 待研究选题与灵感池 (Research Incubator)

## 目录说明
本目录是个人**技术灵感与临时待研究选题的孵化池**。用于快速捕获在日常生产排障、技术交流、架构评审或阅读过程中临时冒出的攻坚想法，防止灵感遗忘，并为后续输出深度技术专题提供源头储备。

## 运转机制（灵感 ──► 攻坚 ──► 归档）
```text
[生产排障/日常突发想法] 
       │
       ▼
[录入 BACKLOG.md 快速捕获]
       │
       ▼
[定期评估梳理：确定优先级与排期]
       │
       ▼
[阶段攻坚：深入源码/内核验证实验]
       │
       ▼
[输出沉淀：闭环归档至 01_Inbox / 06_Troubleshooting]
```
