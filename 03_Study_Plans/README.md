# 03_Study_Plans 学习规划与目标追踪区 (Actionable Roadmap)

---

## 🎯 目录定位与核心价值

- **核心定位**：知识库的**行动引擎与进度仪表盘**。存放阶段性学习路线图（Roadmap）、专项攻坚计划、复习大纲与能力进阶里程碑。
- **核心价值**：
  1. **驱动目标达成**：解决“学什么、按什么顺序学、当前进度如何”的执行力问题，将庞大知识拆解为清晰的阶段任务；
  2. **AI 协同规划**：由 AI 助手根据现有笔记与攻坚方向自动生成复习大纲、测验考卷与打卡清单；
  3. **知识闭环检验**：配合 `02_Notes` 面试题与 `01_Inbox` 深度文档，形成「规划 ──► 学习 ──► 测验 ──► 复盘」的完整学习闭环。
